# Multiple Netherite Addon

网易我的世界（中国版）「多样变种下界合金」独立模组。

作者：**lyingice**（网易我的世界开发者账号：`lyingice`）

> 本模组使用网易 ModSDK 与 `netease:` 系列自定义物品组件，**只能在网易我的世界（中国版）运行**，不能直接用于国际版 Bedrock。全部 114 个自定义物品都依赖 `netease:weapon`、`netease:fire_resistant`、`netease:customtips` 等网易专有组件。

## 内容概览

- 11 个锻造模板：钻石、绿宝石、铁、金、紫水晶、黑曜石、红石、幽冥(echo)、下界之星、铜、青金石
- 11 个变种，每个包含 4 件盔甲 + 5 件工具（剑/镐/斧/锹/锄），共 99 件
- 高级下界合金盔甲 4 件，不含工具
- 121 条锻造台配方
- 48 个盔甲 attachables
- 创造模式物品栏分组：头盔 / 胸甲 / 护腿 / 靴子 / 剑 / 镐 / 斧 / 锹 / 锄 + 锻造模板组
- 下界之星系物品带附魔光效
- 红石质盔甲的移速加成由 ModSDK 服务端脚本实现

## 配方规则

- 所有普通变种均可由「钻石装备 + 对应锻造模板 + 下界合金锭」锻造
- 铁质和金质额外支持「原版铁/金装备 + 对应模板 + 下界合金锭」锻造
- 高级下界合金盔甲由「原版下界合金盔甲 + 下界合金锭」锻造，不使用模板
- 所有锻造配方都使用 `minecraft:recipe_smithing_transform`

## 命名规则

- 模板名称：`下界合金升级·钻石质` 等，11 个模板名称各自唯一
- 变种物品名称统一为 `下界合金剑`、`下界合金镐` 等，材质信息放在物品 Lore 中，只显示两行：
  - `§7已有升级基底：`
  - `§9钻石质`
- 模板描述通过 `netease:customtips` 显示，第一行为 `§7锻造模板`，不重复物品名
- 高级下界合金单独命名为 `高级下界合金头盔` 等

> 由于 11 个变种共用同一套物品名，同部位装备在背包里只能靠 Lore 区分材质。这是当前的设计取舍，详见「已知限制」。

## 安装与使用

- **本地自测**：用网易 MCStudio 打开本目录（工程标识文件为 `studio.json`），直接用「运行」启动测试世界。行为包已在 manifest 中声明对资源包的依赖。
- **玩家安装**：通过网易我的世界开发者平台发布为组件后，玩家从组件中心安装。本仓库只包含工程源码，不包含打包好的 `.mcaddon` / 组件包。

## 已知限制

以下效果尚未实现：

- 紫水晶质的最大生命加成（可用 `AddModifier` + `AttrType.HEALTH` 实现，尚未编写）
- 红石质盔甲的挖掘速度加成（可用 `AttrType.MINING_EFFICIENCY`，尚未编写）
- 金质盔甲的猪灵中立（网易文档没有直接可用的物品属性接口，暂时无法稳定实现）

## 关于生成脚本

`netease_items_beh/`、`netease_recipes/`、`netease_items_res/`、`attachables/` 与两个 `manifest.json` 由一份本地批量生成脚本产出，**该脚本未包含在本仓库中**。修改数值或材料配置后需要重新运行脚本才能重新生成这些 JSON。
